# 公司信息速查 · Company Profile for Codex

输入公司或品牌名称，查询可追溯来源的公司档案，适用于 Codex 的中文 Skill。

## 原型来源与致谢

**这个 Skill 的原型基于抖音博主「布布糕」的想法。我只是在此基础上，做了适用于 Codex 版本的适配与优化。**

原型想法归功于布布糕；本仓库维护者为 Shiya Min（GitHub：[@shiyaminmin-lab](https://github.com/shiyaminmin-lab)）。本仓库不代表原博主的官方发布或背书。

## 查询内容

1. 公司身份：品牌与法律主体、所属国家、总部及注册地。
2. 主营与次要业务。
3. 历年营收与销售规模：明确区分公司营业收入、品牌销售额、电商 GMV 等口径。
4. 主要产品与品牌。
5. 中国区员工人数及统计范围。
6. 在华投资与业务布局。
7. 公开的现任及前员工评价，注明时期、岗位背景与核验限制。

## Codex 适配与优化

- 对同名公司、集团、子公司与品牌进行消歧。
- 扩展到政府、投资方、产权交易、上下游披露、行业报告及渠道监测等资料。
- 找不到精确目标数据时，保留相关补充指标并说明口径，不以整表“未找到”代替研究。
- 保留有信息增量的历史数据、最新期间数据与来源间差异，不将重复转载当作独立印证。
- 对同比（YoY）、环比（QoQ）、复合年增长率（CAGR）作中文解释；自行计算时列出可比基期。
- 对员工评价去重，区分任职自述、匿名说法、媒体转述与招聘宣传。
- 保留原始来源链接、统计时间与信息缺口，不编造未公开的数据。

## 安装

将本仓库放在 Codex 的技能目录下，文件夹命名为 `company-profile`：

```bash
git clone https://github.com/shiyaminmin-lab/company-profile.git ~/.codex/skills/company-profile
```

如果使用了自定义 `CODEX_HOME`，请安装到其 `skills/company-profile` 目录。若目标目录已存在，先检查并保留自己的版本，避免覆盖。

## 使用

在 Codex 中调用：

```text
使用 $company-profile 查询百词斩
```

也可以指定时间范围或重点：

```text
使用 $company-profile 查询毕生之研，重点整理近五年营收、渠道销售额和公开员工评价，并解释不同统计口径。
```

需要可用的联网搜索与页面读取能力；本 Skill 不捆绑付费数据库或登录凭证。搜索不到不等于公司没有相关业务或从未披露，公开员工评价也不代表全体员工。
